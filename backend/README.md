# backend/

> 🔓 Some tools for this folder are still open decisions — see [#58](https://github.com/marieashtonkoehl/IoT_final_project_2026/issues/58). This README will be updated once the team decides.

The API (web framework to be decided): REST over HTTP with JSON, documented with OpenAPI. Handles the cooldown + daily cap rules, storage in the time-series database, external APIs (weather, air quality, green spaces), alerts and analytics.

- `app/`: the server code itself
- this folder: things about the server: README, list of Python packages, tests
